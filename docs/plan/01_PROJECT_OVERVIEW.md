## 6. เนื้อหาวิชาการ (Domain knowledge) — ฉบับที่ถูกต้อง ใช้เป็นแหล่งอ้างอิงของทีม

### 6.1 ชนิดเนื้อเยื่อกล้ามเนื้อ (OL1)

| | Skeletal | Cardiac | Smooth |
|---|---|---|---|
| การควบคุม | **Voluntary** (somatic NS) | Involuntary (autonomic NS) | Involuntary (autonomic NS) |
| ตำแหน่ง / หน้าที่ | ยึดกระดูก → เคลื่อนไหวร่างกาย | ผนังหัวใจ → สูบฉีดเลือด | ผนังอวัยวะภายใน (ทางเดินอาหาร, ทางเดินหายใจ, หลอดเลือด, ciliary body, arrector pili) |
| ลาย (striation) | Striated | Striated | **Non-striated** |
| รูปร่างเซลล์ | ทรงกระบอก ยาว | สั้น **แตกแขนง (branched)** | สั้น **รูปกระสวย (spindle / fusiform)** |
| Nucleus | **หลายอัน อยู่ขอบเซลล์ (multinucleated, peripheral)** | 1 (บางครั้ง 2) อยู่กลาง | 1 อยู่กลาง (รูปไข่) |
| จุดเด่น | – | **Intercalated disc** = desmosome + gap junction | – |

### 6.2 การจัดเรียงโครงสร้าง (OL2, OL3) — เล็ก → ใหญ่

| ขนาดเส้นผ่านศูนย์กลาง | โครงสร้าง | Connective tissue ที่หุ้ม |
|---|---|---|
| 5–6 nm | **Thin filament** (actin + tropomyosin + troponin) | – |
| 10–12 nm | **Thick filament** (myosin) | – |
| 1–2 µm | **Myofibril** (sarcomere ต่อกันเป็นสาย ล้อมด้วย sarcoplasmic reticulum) | – |
| ~100 µm (ตาม Key Point Book) | **Muscle fiber (cell)** — เยื่อหุ้ม = sarcolemma (ยื่นเป็น T-tubule) | **Endomysium** |
| – | **Fascicle** (มัดของ muscle fiber) | **Perimysium** |
| – | **Skeletal muscle** (ทั้งมัด) | **Epimysium** |

### 6.3 ระดับเซลล์

- **Sarcolemma** — เยื่อหุ้มเซลล์กล้ามเนื้อ ยื่นลึกเข้าไปเป็น **T-tubule** เพื่อส่งสัญญาณไฟฟ้า
- **Sarcoplasm** — ไซโทพลาซึม มี mitochondria และ myoglobin
- **Sarcoplasmic reticulum (SR)** — เก็บและปล่อย **Ca²⁺**
- **Neuromuscular junction:** motor neuron → axon terminal (vesicle บรรจุ **acetylcholine**) → synaptic cleft → ACh receptor บน sarcolemma → สัญญาณวิ่งผ่าน T-tubule → SR ปล่อย Ca²⁺ → contraction
- **Motor unit** = motor neuron 1 ตัว + muscle fiber ทั้งหมดที่มันควบคุม

### 6.4 Sarcomere (OL4, OL5) — หัวใจของโปรเจกต์

| ส่วน | นิยาม |
|---|---|
| **Sarcomere** | ช่วงจาก **Z-disc ถึง Z-disc** = หน่วยการหดตัว (functional unit) |
| **Z-disc (Z-line)** | ขอบเขตของ sarcomere ที่ thin filament ยึดอยู่ |
| **M-line** | เส้นกึ่งกลาง sarcomere ยึด thick filament |
| **A-band** (แถบเข้ม) | ความยาวทั้งหมดของ thick filament — **มีทั้ง thick และส่วนของ thin ที่ซ้อนทับ** |
| **H-zone** | กลาง A-band ที่มี **เฉพาะ thick filament** |
| **I-band** (แถบสว่าง) | ส่วนที่มี **เฉพาะ thin filament** คร่อม Z-disc |

**โปรตีน:**
- **Thin filament** = **Actin** (F-actin เกลียวคู่ มี binding site ของ myosin) + **Tropomyosin** (ปิด binding site ขณะพัก) + **Troponin complex** (**TnC, TnI, TnT**)
- **Thick filament** = **Myosin** (มี head จับ actin และ ATP + tail)
- โปรตีนโครงสร้าง: **Titin** (ความยืดหยุ่น), **Nebulin**
- ⚠️ ข้อที่นักศึกษาผิดบ่อยที่สุด: **myosin ไม่ใช่องค์ประกอบของ thin filament**

**ขณะหดตัว (Sliding filament theory):**

| ส่วน | Contraction |
|---|---|
| Sarcomere | **สั้นลง** (Z-disc เลื่อนเข้าหากัน) |
| I-band | **สั้นลง** |
| H-zone | **แคบลงจนหายไป** |
| A-band | **ยาวเท่าเดิม** |
| Thin / Thick filament | **ยาวเท่าเดิม** แค่เลื่อนซ้อนกัน |
